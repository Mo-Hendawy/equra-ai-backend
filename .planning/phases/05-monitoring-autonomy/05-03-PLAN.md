  <name>Task 1: Add getMetrics() to MemoryService</name>
  <files>server/memory/memory-service.ts</files>
  <action>
    Add a `getMetrics()` method to the `MemoryService` class. It must be synchronous (all data is in SQLite, no async needed) but return a Promise for API consistency. Return type:

    ```typescript
    interface AgentMetrics {
      decisionsToday: number;
      criticOverrides: number;   // decisions where critic severity was 'high' AND confidence was discounted
      avgConfidence: number;     // 0-100 scale: High=100, Medium=60, Low=30; average over all decisions
      backtestAccuracy: number;  // 0-100: % of scored decisions where recommendation direction matched outcome
    }
    ```

    Implementation:

    1. `decisionsToday`: fetch all decisions where `createdAt >= start of today (Cairo UTC+2)`. Start of today = `new Date()` set to midnight Cairo: `const todayStart = new Date(); todayStart.setHours(todayStart.getHours() - 2); todayStart.setHours(0, 0, 0, 0); todayStart.setHours(todayStart.getHours() + 2);`. Simpler alternative: compute epoch for today 00:00 Cairo = `Date.now() - (Date.now() % 86400000) - (2 * 3600000)` and filter `createdAt.getTime() >= todayStartEpoch`. Count the results.

    2. `criticOverrides`: count decisions where `criticSeverity === 'high'`. These are the decisions where the critic's severity was highest and a confidence discount was applied (per Phase 2 design: high severity → -20% confidence discount). Count from all decisions.

    3. `avgConfidence`: map confidence strings to numbers: `'High' → 100`, `'Medium' → 60`, `'Low' → 30`. Compute mean over all decisions. If no decisions, return 0.

    4. `backtestAccuracy`: from decisions where `outcome5d IS NOT NULL`:
       - A recommendation is "correct direction" if:
         - recommendation is `'Strong Buy'` or `'Buy'` AND `outcome5d > 0`
         - recommendation is `'Strong Sell'` or `'Sell'` AND `outcome5d < 0`
         - recommendation is `'Hold'` — count as correct always (neutral)
       - `backtestAccuracy = (correct / total_scored) * 100`. If no scored decisions, return 0.

    The method signature:
    ```typescript
    async getMetrics(): Promise<AgentMetrics>
    ```

    Use `this.db.select().from(decisions).all()` to fetch all decisions at once, then compute all four metrics in-memory from that single array. This is efficient enough for the expected decision count (hundreds, not millions).
